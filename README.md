# OnePointZero apps

Installers for **OnePointZero** — *One Platform. Zero Spreadsheets.* — and the **OPZ Scanner**.
This repository holds downloads only; there is no source code here.

| App | Download (always the latest version) |
|---|---|
| OnePointZero for Android | [OnePointZero-Android.apk](https://github.com/onepointzero-edu/opz-apps/releases/download/onepointzero/OnePointZero-Android.apk) |
| OnePointZero for Windows | [OnePointZero-Windows-Setup.exe](https://github.com/onepointzero-edu/opz-apps/releases/download/onepointzero/OnePointZero-Windows-Setup.exe) |
| OPZ Scanner for Android | [OPZ-Scanner.apk](https://github.com/onepointzero-edu/opz-apps/releases/download/opz-scanner/OPZ-Scanner.apk) |

You can also use OnePointZero in the browser at <https://onepointzero-edu.web.app>.

## Installing on Android
1. Download the APK on your phone and open it.
2. If asked, allow **Install unknown apps** for the app you opened it from (Chrome, Files, Messenger…).
3. Play Protect may say the app is unrecognised; that's expected for apps not from the Play Store.
4. Sign in with your OnePointZero account.

## Installing on Windows
Run `OnePointZero-Windows-Setup.exe`. If Windows SmartScreen appears, choose **More info → Run anyway**.

Updates: download again from the same link; it installs over the old version and keeps your data.
